# Шахматы: Проверка хода фигуры

Простая программа на Python, которая проверяет, может ли шахматная фигура (ладья, король, слон, конь, ферзь) попасть с одной клетки на другую за один ход.

## 🕹️ Как это работает
1. Программа спрашивает название фигуры.
2. Спрашивает координаты начальной клетки (x1, y1) и конечной (x2, y2).
3. Выводит `YES`, если ход возможен, и `NO` в противном случае.
